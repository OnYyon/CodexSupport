# C++ — изометрическое путешествие

Результат: `../OOP_CPP20_Battle_Journey.html`. Открывается локально без сервера и интернета. Сборка встраивает Three.js, его MIT-лицензию, материалы восьми лекций, банк вопросов и резервные иллюстрации.

## Визуальный замысел

Ракурс сверху под углом, как в MOBA: камера с небольшим перспективным сокращением, общий трёхмерный мир, настоящие тени. Рыцарь, оружие, четыре типа противников, ворота, деревья, камни, трава и дорога — оригинальная процедурная геометрия. Это стилизованные модели, а не импортированные персонажи Dota 2. Поворот камеры меняет видимые поверхности моделей.

Референс движения: https://emotion-agency.com/ — крупная типографика, пространственная сцена и светящиеся частицы. Здесь собственный символ C++ складывается из 2200 частиц над дорогой; в перелёте частицы разлетаются. Текст появляется каскадом, камера плавно сопровождает путь, меняет азимут между главами и приближается во время удара. Материалы и код референса не копируются.

## Учебный цикл

Восемь полных лекций берутся из актуального Markdown при сборке. Чтение → выход на дорогу → серия вопросов. Пять правильных ответов побеждают стража. Две ошибки возвращают к конспекту с отмеченными темами и объяснениями. Повторное сражение сначала проверяет темы ошибок. Во время анимации повторный ответ заблокирован. Локально сохраняются пройденные главы и темы для повторения.

## Реализация

- `scene3d.js`: WebGL, физические материалы, скелет из групп, шарнирная походка, замах/удар, ответ монстра, падение/исчезновение, искры, движущийся плащ, частицы портала, плавная камера.
- `scene.js`: резервная Canvas-сцена для устройств без WebGL.
- `model.js`, `content.py`, `app.js`: состояние, вопросы, чтение, библиотека, интерфейс.
- `vendor/`: закреплённая Three.js r158 и MIT-лицензия. Зависимость встроена, CDN при открытии не используется.
- Системное уменьшение движения и кнопка MOTION OFF отключают движение, сохраняя результаты ответов. Диалоги приостанавливают сцену; возврат не перескакивает через анимацию.

## Проверка

```sh
/tmp/oop-review-env/bin/python build_battle.py
node --check battle-journey/scene3d.js
node --check battle-journey/app.js
node battle-journey/test_model.cjs
node battle-journey/test_scene3d.cjs
```

Модель: победа, два промаха, повторение, восемь глав, сохранение, недопустимый ввод, двойной клик, 200 случайных боёв. 3D: настоящие объекты Three.js с заглушкой только GPU, восемь глав × пять режимов × три размера экрана, конечные координаты, попадание героя/портала в кадр, завершение анимаций и пауза. Рендер WebGL дополнительно просмотрен в Chrome на настольном экране. На физическом телефоне производительность не измерялась.
