# Лаборатория вероятностей

Учебные главы и карточки лежат в `materials/` в Markdown. Встроенная математика записана между одиночными знаками доллара, отдельные формулы — между двойными. В `cards.md` заголовок карточки содержит постоянный идентификатор, раздел и вопрос, разделённые вертикальной чертой.

Директива `{{graph:normal}}` вставляет интерактивный график из `distribution-models.js`. После сборки открой сайт через статический HTTP-сервер, чтобы браузер мог загрузить модули графиков.

Для сборки с Node.js 22 или новее:

```sh
npm ci
npm run build
```

Сборка записывает статический сайт в `dist/`. Формулы отрисовываются на этапе сборки, шрифты KaTeX загружаются с самого сайта. Для обновления GitHub Pages содержимое `dist/` размещается в корне ветки `gh-pages`.
